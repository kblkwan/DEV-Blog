At this stage, we do not yet have a functioning prototype to test. However, we plan to conduct user testing to validate key assumptions and concerns identified earlier in the design process around compromises made to improve feasibility. This can be done through think aloud, Wizard of Oz testing, and asking participants to annotate wireframes to provide feedback on how they envision the community hub would function.

In phase 1, we would like to test whether:
- [ ] The design is intuitive and easy to navigate
- [ ] Users can identify key features within the site
- [ ] Users can find a service using filters
- [ ] Users find value in the community hub
- [ ] Core tasks can be completed efficiently with minimal guidance
- [ ] Any parts of the interface create unnecessary friction or cognitive load

Once our working prototype is available, testing will focus on system level checks, including whether data is correctly retrieved and displayed, and whether key user interactions such as searching, filtering, and posting function as intended. This will also help identify any performance issues or usability barriers that may not have been evident during the design phase. We anticipate that testing can begin once a basic user flow has been implemented, allowing us to validate core functionality early. Early stage testing will help identify bugs and inconsistencies before using existing components as a foundation to scale and refine the system.

## Basic User Flow

|  | User Action | System Response |
|------|------------|-----------------|
| 1 | Business advertises their services on their profile and/or creates a post| The user’s profile and/or post becomes visible within the community feed |
| 2 | User chooses to publish a post to request help from others | The system opens the 'Create Post' interface |
| 3 | User writes and submits a post outlining their request | The system validates and prepares the post for publishing |
| 4 | User submits the post | The system publishes the post to the community feed or marketplace |
| 5 | Users can discover other peoples post on the explore page | The algorithm directs users to the relevant posts |
| 6 | Users contact service providers | Communicate through direct messaging |

## Next Steps
In the coming weeks, we aim to: 
- [ ] Have a working prototype for a basic user flow
- [ ] Ensure the design meets AA accessibility standards
- [ ] Refine backend data structures and systems
- [ ] Complete user testing and analysis
